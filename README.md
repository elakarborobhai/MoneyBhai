# Money Bhai

Money Bhai is a private, offline-first Progressive Web App designed to help users track betting sessions, manage finances, and make smarter decisions — with dignity, privacy, and control.

## Features
- ✅ Consent & Disclaimer gate
- ✅ Taka Manager: Add/view transactions, net P&L
- ✅ Hisab Engine: Log bets, detect patterns
- ✅ Promotions Tracker: Bonus progress and suggestions
- ✅ Education Library: Learn key concepts
- ✅ Offline support via service worker

## Tech Stack
- HTML, CSS, JavaScript
- IndexedDB for local storage
- Tailwind CSS (optional)
- Vite (recommended for dev)
- GitHub Pages (optional for hosting)

## Privacy
- No cloud sync
- No telemetry
- All data stored locally in browser

## Getting Started
Clone the repo and open `index.html` in your browser. Or enable GitHub Pages to run it online.
