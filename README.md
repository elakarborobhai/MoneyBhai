## Overview
Money Bhai stores and analyzes betting sessions and transactions locally on the device, provides wagering progress and promotion tracking, and nudges users toward safer betting habits. This repository contains an Android app skeleton implemented in Kotlin + Jetpack Compose with Room for local storage.

## Features
- Hisab Engine session and bet logging
- Bonus Bhai promotions tracker and wagering progress
- Taka Manager bankroll ledger and Baki Hisab
- Bebostha Ache on-device alerts and micro-education in Bangla
- Offline-first, local-only data by default
- Optional user-initiated encrypted backups
